# Modelo Esquema no Supabase

Coloque aqui os prints do esquema do banco dentro do Supabase.

## Como conseguir os prints

1. Crie um projeto no [Supabase](https://supabase.com/dashboard).
2. Abra **SQL Editor**, cole e rode `../Tabelas/01_create_tables.sql`.
3. Rode `../Testes/02_insert_into.sql` para carregar os dados.
4. Abra **Database > Schema Visualizer** (no menu da esquerda, em Database), escolha o schema `public` e tire o print do diagrama com as 18 tabelas e as ligações.
5. Abra **Table Editor** e tire um print da lista de tabelas.
6. Salve as imagens nesta pasta, por exemplo `schema-visualizer.png` e `table-editor.png`.

## Link público

Cole o link público do projeto no `README.md` da raiz do repositório (seção "Links").
