# MAPERE — Aracaju

Protótipo clicável do MAPERE: mostra se um eletroposto está livre e funcionando agora, com a idade da informação.

- Locais, endereços e plugues: reais, de listas públicas (Aracaju - SE).
- Status, preços, vagas, relatos e vantagens: **simulados**.
- Site estático (HTML/CSS/JS). Mapa: OpenStreetMap + Leaflet.
- Publicação: Vercel (cada push na `main` publica em produção).
